Program to downgrade a newer version of Studio 5000 .L5K file to an older version .L5K file  (ex. go from V37 to V34)

This will make the changes to the .L5K file to make it the downgraded version you chose. 
Next, open FT Studio 5000 and Import the .L5K file.  It will give you a few warnings, and you may need to edit the new .ACD file to fix any issues.

Obviously, if you had newer features and/or products that weren't supported on the downgraded version you will need to address those issues.

I wrote this for myself to make it easier to downgrade projects.  If it works for you great.
